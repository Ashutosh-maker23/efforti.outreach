Follow-up cadence

How many working days (Mon–Fri) to wait before each follow-up. Weekends never count toward a gap and no email is ever sent on a Sat/Sun, so the sequence stays inside the week. This applies the same gap to every follow-up touch — currently every {{cadence}} working days. The default sequence is spaced 3, 4, 5, 4 (touches on working days 3, 7, 12, 16); use this only to flatten it to a single gap.

Example at every 3 working days: opener on day 0, follow-up 1 three weekdays later, follow-up 2 three weekdays after that — weekends skipped. You can still fine-tune any individual step's wait below.
